🧠 How Memory & Session Generation Works

The API provides continuous conversation memory across multiple messages using session_id.

1

Generate a Session ID

Request a fresh session ID with initial character greeting:

GET /api/chat?action=new_session&character=Kohana
2

Chat with Memory

Include session_id in your subsequent GET requests:

GET /api/chat?prompt=My+name+is+John&session_id=sess_Kohana_1234
3

AI Remembers Everything

Follow up with any question relying on past messages:

GET /api/chat?prompt=What+is+my+name?&session_id=sess_Kohana_1234

📖 API Endpoints Reference

1. Chat Endpoint with Memory (GET)

GET /api/chat?prompt={message}&character={name}&session_id={id}

Query Parameters:

Parameter Type Required Description
prompt string Yes (for chat) The message to send. Aliases: text, message, q.
character string No Character name (e.g. Kohana, Linda, Sarah Wood). Default: Kohana.
session_id string No Session ID for memory. If not provided, a new one is auto-generated and returned.
action string No Special actions:
• new_session: Creates a new session ID with character greeting.
• history: Returns all stored messages for a session_id.
• clear: Clears memory for a session_id.
username string No Your persona / display name. Default: Guest.
format string No json (default) or text (raw reply string only).

2. Generate Session Endpoint (GET)

GET /api/chat?action=new_session&character=Kohana

3. View Memory History (GET)

GET /api/chat?action=history&session_id=sess_Kohana_afbe9974d87a391f

4. List Characters (GET)

GET /api/characters

🚀 Deploying to Netlify & GitHub

  1. Push to GitHub: Initialize git, commit, and push to your repo.
  2. Import to Netlify: Log into Netlify → Add new site → Import an existing project → pick your GitHub repository.
  3. Auto-detected Settings: Netlify detects netlify.toml automatically. Click Deploy.
  4. Your live API with memory is ready at https://<your-site>.netlify.app/api/chat?prompt=hello!
