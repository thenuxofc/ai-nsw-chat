📖 Developer Documentation

Simple and clean GET REST API endpoints with persistent context memory.

1. Chat Endpoint (GET)

GET https://thenuxaislut.netlify.app/api/chat

Send a message to any AI girl and receive an instant intelligent response with context memory.

Parameters:

Param Type Default Description
prompt string required Message to send. (Aliases: text, message, q).
character string Kohana Character name or ID (e.g. Kohana, Linda, Miranda).
session_id string auto Memory key to maintain conversation thread. Auto-generated if omitted.
format string json Use text for raw string reply (ideal for bots/cURL).
username string Guest Display name of the user.

2. Session Actions

  • Create New Session: GET /api/chat?action=new_session&character=Kohana
  • View Stored Memory: GET /api/chat?action=history&session_id={session_id}
  • Clear Memory: GET /api/chat?action=clear&session_id={session_id}
  • List All Characters: GET /api/characters

3. Code Examples

cURL

# Plain text response
curl "https://thenuxaislut.netlify.app/api/chat?prompt=hello&character=Kohana&format=text"

# JSON with memory
curl "https://thenuxaislut.netlify.app/api/chat?prompt=hello&session_id=sess_Kohana_123"

JavaScript / Node.js

const res = await fetch("https://thenuxaislut.netlify.app/api/chat?prompt=Hello&character=Kohana");
const data = await res.json();
console.log(data.reply);
