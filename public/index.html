📖 API Documentation

1. Chat Endpoint (GET)

GET /api/chat

Use this endpoint to chat with any character with a simple GET URL.

Query Parameters:

Parameter Type Required Description
prompt string Yes The message you want to send. Aliases: text, message, q.
character string No Name or slug of the character (e.g. Kohana, Linda, Sarah Wood). Default: Kohana.
session_id string No Optional session ID to maintain continuous context. Auto-generated if omitted.
username string No Your persona / display name. Default: Guest.
format string No json (default) or text (returns just the AI reply string).

Example JSON Response:

  "status": "success",
  "character": "Kohana",
  "character_id": "Kohana",
  "prompt": "Hello!",

2. List Characters Endpoint (GET)

GET /api/characters

Returns a complete list of all characters with avatars, descriptions, tags, and greetings.

3. Integration Code Examples

cURL

# GET Request
curl "https://your-site.netlify.app/api/chat?prompt=hello&character=Kohana"

# Get pure text reply
curl "https://your-site.netlify.app/api/chat?prompt=hello&character=Kohana&format=text"

JavaScript / Fetch

const response = await fetch("https://your-site.netlify.app/api/chat?prompt=Hello&character=Kohana");
const data = await response.json();
console.log(data.reply);

Python

import requests

res = requests.get("https://your-site.netlify.app/api/chat", params={
    "prompt": "Hello darling",
    "character": "Kohana"
})
print(res.json()["reply"])

🚀 Deploying to Netlify & GitHub

  1. Push to GitHub: Initialize git, commit your files, and push to your GitHub repository.
  2. Import to Netlify: Log into Netlify → click "Add new site" → "Import an existing project" → select your GitHub repo.
  3. Deploy Settings: Netlify will automatically detect netlify.toml. Click Deploy!
  4. Your live GET API is instantly online at https://<your-site>.netlify.app/api/chat?prompt=hello!
